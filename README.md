# customer-purchase-prediction-ml
End-to-end E-commerce Customer Behavior Analysis project using Python, Pandas, Scikit-learn, and Machine Learning. Includes data cleaning, feature engineering, exploratory analysis, and purchase prediction models.
📌 Project Objective
The goal of this project is to:
- Clean and preprocess customer data
- Analyze customer behavior
- Perform feature engineering
- Build machine learning models to predict purchase behavior

---

## 📊 Dataset Features
- Age
- Gender
- Device Type
- Time on Site
- Pages Viewed
- Previous Purchases
- Cart Items
- Returning User
- Purchase Status

---

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## 🔍 Steps Performed
1. Data Cleaning
2. Missing Value Handling
3. Duplicate Removal
4. Feature Engineering
5. Exploratory Data Analysis
6. Logistic Regression Model
7. Random Forest Model

---

## 🤖 Machine Learning Models
- Logistic Regression
- Random Forest Classifier

---

## 📈 Results

- Random Forest Accuracy: ~99%
